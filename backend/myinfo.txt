✅ Step 1: Setting Up the Backend
1️⃣ Create the Backend Folder
👉 Open Command Prompt (Windows) or Terminal (Mac/Linux) and run:

sh
Copy
Edit
mkdir netflix-backend
cd netflix-backend
This creates a new folder named netflix-backend and moves into it.

2️⃣ Initialize a Node.js Project
Inside the netflix-backend folder, run:

sh
Copy
Edit
npm init -y
🔹 This creates a package.json file, which keeps track of dependencies and project details.

✅ Step 2: Installing Dependencies
Now, install the required packages:

sh
Copy
Edit
npm install express mongoose dotenv cors bcryptjs jsonwebtoken
📌 What These Packages Do?
Package	Purpose
express	Backend framework for handling API requests.
mongoose	Connects to MongoDB and allows database interactions.
dotenv	Stores secret data (like database URLs) in a .env file.
cors	Allows frontend (React) to communicate with backend.
bcryptjs	Encrypts passwords for security.
jsonwebtoken	Generates and verifies tokens for authentication.
🔹 Install nodemon (optional but useful):

sh
Copy
Edit
npm install --save-dev nodemon
Why?

nodemon restarts the server automatically when changes are made.
